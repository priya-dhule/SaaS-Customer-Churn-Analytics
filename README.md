# SaaS Customer Churn Analytics

## Project Overview
This project focuses on analyzing SaaS customer behavior, subscription revenue, product usage, and customer churn to identify business insights and opportunities for customer retention.

## Tools & Technologies
- Microsoft Excel – Data cleaning, formulas, Pivot Tables and analysis
- MySQL – Data querying and business analysis
- Power BI – Interactive dashboard and data visualization

## Project Objectives
- Analyze customer churn across plans and locations.
- Understand customer engagement and product usage.
- Identify payment failures and support ticket trends.
- Analyze subscription revenue and churn-related revenue.
- Provide recommendations to improve customer retention.

## Project Workflow
1. Data cleaning and analysis using Excel.
2. Business queries and analysis using MySQL.
3. Data modeling and dashboard development using Power BI.
4. Insights and recommendations based on analysis.

## Key Insights
- Healthcare had the highest churn rate in the Excel analysis (32.76%).
- CRM Module had the highest escalated-ticket rate in the SQL analysis (14.88%).
- In the Excel dataset, churned customers accounted for approximately 31.43% of paid revenue.
- Some churned customers showed zero logins in the previous calendar month.

*Note: Excel and SQL results are based on different data populations because the SQL import contains fewer records. Their results should not be directly compared.*
